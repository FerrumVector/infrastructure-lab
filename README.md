# FerrumVector Infrastructure Lab

A hands-on small-business IT infrastructure lab focused on practical networking, virtualization, Windows Server, monitoring, backup, secure service deployment, and private AI integration.

## Scope

- Proxmox virtualization
- Windows Server and Active Directory
- Network segmentation and firewalling
- Small-business endpoint and device management
- Monitoring and alerting
- Backup and recovery
- Secure remote access
- Private AI infrastructure
- Client environment simulation

## Purpose

This lab is used to design, test, and document realistic infrastructure solutions for small-business environments.

The goal is to build repeatable deployment patterns for networking, servers, endpoints, monitoring, backup, and local AI services.

## Current Platform

- AMD Ryzen 9 9950X virtualization host
- 96GB DDR5-6000 memory
- 2TB SK hynix P41 NVMe for host and primary VM storage
- 4TB NVMe thin-provisioned VM storage
- Proxmox VE
- Windows Server 2025
- Windows 11 client VMs
- Ubuntu services
- 10GbE network connectivity
- NAS-backed storage and backup
- NVIDIA RTX 5060 Ti 16GB for local AI workloads
